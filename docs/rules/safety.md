# 안전 규칙

- 공개 저장소에 token, 비밀번호, 인증서, 개인정보와 `.env` 내용을 기록하지 않습니다.
- API 계약 변경은 client와 AI 연동 호환성을 먼저 확인합니다.
- database schema와 migration 변경은 데이터 영향과 rollback 방법을 PR에 적습니다.
- 인증·권한·공통 middleware 변경은 충돌 위험도를 최소 `보통`으로 검토합니다.
- 삭제, 공개, 배포와 비용이 발생하는 작업은 실행 전에 대상·영향·복구 방법을 확인합니다.
- 기존 변경을 임의로 되돌리거나 현재 Issue와 무관한 파일을 commit하지 않습니다.
